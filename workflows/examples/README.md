# LEGACY / EXAMPLE WORKFLOWS

Все JSON в этой папке — условные архитектурные примеры раннего проектирования.

- Они не являются основным production path.
- Они не подтверждают наличие нужных models/custom nodes на backend.
- Они не должны отправляться на генерацию как готовые workflow.
- Их можно использовать только как справочные схемы полей и связей.

Основной pipeline описан в [`../../docs/PRODUCTION_PIPELINE.md`](../../docs/PRODUCTION_PIPELINE.md). Реальные опубликованные workflow и источники находятся в [`../real_examples/`](../real_examples/README.md).
